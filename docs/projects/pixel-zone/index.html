Pixel Zone: an AI Arabic newsroom

An experiment in turning sourced news into clear Arabic editorial packages, combining source discovery, structured AI editing, visual production and human review, with a companion mobile app for publishing.

Actual status
Working prototypes, human-reviewed, automatic publishing paused
My role
Concept, editorial requirements, workflow direction, visual review and AI-assisted development

Decisions I made

  • Keep source links and distinguish between levels of source confidence.
  • Use structured model outputs and deterministic checks.
  • Design separately for each publishing format.
  • Keep a human approval step, and make publication state explicit.

What it covers

  • Source ingestion and deduplication
  • Arabic AI editing and classification
  • Prompt versioning and post-generation checks
  • Automated rendering and overflow checks
  • Local editorial memory learned from skip decisions
  • Android review and publishing queue

Implementation environment

  • OpenAI Responses API
  • Python
  • FastAPI
  • n8n
  • PostgreSQL
  • Remotion
  • Docker Compose
  • Android
